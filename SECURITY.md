# Security Policy

## Reporting a security issue

Report suspected vulnerabilities or unauthorized access privately to:

**Email:** `jessiemcghee1984@gmail.com`  
**Subject:** `SECURITY REPORT - traceops-alpha-ai`

Do not include customer evidence, passwords, private keys, recovery codes, full financial-account numbers, or unnecessary personal information in the initial message.

## Responsible handling

- Do not publicly disclose an unremediated vulnerability.
- Do not access, alter, download, retain, or disclose customer data or evidence.
- Do not use social engineering, credential attacks, denial of service, destructive testing, or testing against third-party systems.
- Stop immediately if testing encounters private data, evidence, secrets, or another person's account.
- Preserve relevant timestamps, URLs, request identifiers, and non-sensitive reproduction steps.

## Scope and authorization

This file does not authorize security testing. Written scope and authorization are required before active testing. Reports made in good faith will be reviewed, but no bounty, safe harbor, or payment is promised unless separately agreed in writing.

## Emergency response

A suspected compromise affecting credentials, customer data, payment controls, domains, source repositories, or cloud root access must be treated as a restricted incident and escalated to the Founder.

> **DRAFT - ATTORNEY AND SECURITY REVIEW REQUIRED.**
